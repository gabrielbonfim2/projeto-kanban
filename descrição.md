# Quadro Kanban


## Funcionalidades
- Criar cards
- Arrastar cards entre colunas
- Editar card com duplo clique
- Excluir cards
- Salvar tarefas no navegador com localStorage
- Layout responsivo

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- Drag and Drop API
- localStorage
- Git e GitHub
- Vercel
